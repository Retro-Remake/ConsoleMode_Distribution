== 1.1.4
New in this release:

- Music Player. MP3, FLAC and WAV from SD, USB and network. Browse by folder or library.
- Now Playing screen with visualiser, seek bar, transport controls and embedded cover art.
- Music section on the main menu. The CD player moved here from Dev Tools.
- Background Music and System Sounds submenus, Dynamic BGM, WAV for UI sound slots. Audio now lives under ConsoleMode/Sounds.
- Ports section group. Duke3D, Quake, 3S-ARM, PICO-8 and Sonic Mania, with their own tiles and logos. Single-core systems launch straight from the system view.
- PICO-8 carts show their own art, .p8.png directly and .p8 label decode.
- Neo Geo Pocket and Neo Geo Pocket Color via the jtngpc core.
- Category Icons setting with a new dark tile set, dark by default.
- Boot To: Main Menu, Load Game, History or Favorites.
- Time Zone picker. Browses the zoneinfo db, applies live and sets the system zone so FAT timestamps match.
- Folder favorites for multi-disc games and collections.
- Hide folders from the browser, same as hiding a game.
- Per-pad Confirm/Back swap in the controller options menu.
- Scrape media toggle: box art, backgrounds or both.
- ScreenScraper scraping now works with a free ScreenScraper account. The developer id ships with Console Mode, so you only add your own ssid/sspassword.
- Favorite stars show on search results.
- Nested folder position inside a system is remembered across launches.
- Core select shows a port's wrapper binary and whether the active ini sets it.
- Category labels follow the section ini filename as typed.
- Famicom-family and 11 more list logos, rename-proof lookup.
- Atari 2600 lists .bin, 3DO accepts .iso, PSX2XCPU resolves as a PSX core.
- WiFi Disconnect keeps the password. Wired networks get a header icon.
- Writes /tmp/ACTIVEGAME at launch for Zaparoo-style trackers.
- Rounded selection toggle. List view drops the backing card behind category tiles.

Fixes

- Music Section toggle had no handler, so it could never be turned off.
- Music folders with case variants tripled the roots on case-insensitive mounts.
- BGM started under the loading bar instead of after the first menu frame.
- BGM kept playing when the selected source had nothing in it, and ran over Optimize Artwork.
- Frontend didn't exit cleanly on shutdown, so a stale frame could stay onscreen.
- Scraped media dropped dots from titles, and folder art didn't resolve under the folder's own name.
- Scraper wrote to network media dirs without a working mkdir or copy fallback.
- Scraper used a nonexistent Apple II thumbnail set and the wrong Atari 800 repo name.
- RetroAchievements wrote the rbf stem instead of the core's CONF_STR ini section.
- Pad face buttons ignored the input map when BTN_DPAD defaults were present.
- Titles that are only a tag kept the wrong name, and .p8 shed one extension too few.
- Settings cursor lost its place returning from a submenu.
- Near-opaque art missed the fast blit path.

== 1.1.3
New in this release:

- Cifs support.
- Added new CRT modes: 480p, 576p, 640x480p.
- Bundled configs- section inis + cacert.pem baked into the binary and installed/upgraded at boot. Edited inis aren't upgraded.
- OTA is multi-file mode now.
- BGM music with volume and Static/Dynamic modes. Add mp3s to ConsoleMode/Sounds/BGM.
- User UI sounds for confirm, back, and nav. Add MP3s to ConsoleMode/Sounds/SystemSounds.
- Virtual Boy system support.
- Big NX View game style. Based on SS4-selected cover sizes. Great for 240p CRT.
- Keyboard type-jump. Any letter or digit jumps the list to that key.
- Custom background color in the 7th swatch via hex entry.
- Add ability to edit MiSTer INI from CM + HDR toggle.
- Boot to Load Game toggle.
- Hide Categories toggles.
- Center list option for list view.
- Load Core changed into stock MiSTer Menu behavior.
- Add / for search and + for favorites.
- Report Bugs/Feedback QR screen.
- names.txt support.
- Hidden disc collapse. Folder with one visible cue launches into the game.
- File-based romDirs.
- Main-BG backdrop support for category and system views.
- CD-i & 3DO list icons.
- Game options show full filename.
- Footer select label changed to SEL.

Fixes

- OTA could die on missing CA bundle.
- Fix bug in main MiSTer video modes.
- Hidden games would linger after being hidden.
- SS4 section tiles stretched their icons instead of decoding at the new target size.
- Alias-resolved titles skipped a () title filter (Neo-Geo).
- Artwork optimizer re-processed already-optimized files, but didn't write them again, essentially wasting decode cycles.
- Scraped art resolves for titles with dots in the name (v1.1 style).
- RetroAchievements core override writes the ini section the core reads (TGFX16).

== 1.1.2
What's new:

- CRT mode: fixed the frame rate collapse and rolling black flicker that
  appeared whenever overscan was set above 0%.
- CRT overscan now trims the layout instead of scaling the picture, so it
  stays sharp. Range is 0-5%.
- CRT menu core: reworked video timing, which makes the signal much easier
  to centre, plus a flicker filter for the interlaced modes.
- Controller mapping: d-pads, Select/Start, and triggers now map correctly
  on the pads that previously failed, and analog sticks can be mapped.
- Mapping reads controller identity from MiSTer instead of overwriting its
  map, so pads keep working in the OSD.
- Hold Back for two seconds to leave the mapper if you start a capture by
  mistake.
- A/B swap is gamepad-only now: keyboard Enter and Escape stay put, and the
  on-screen button prompts follow the swap.
- System config updates for 0MHz DOS, Neon68K X68000, AmigaVision, and
  Amiga CD32.

== 1.1.1
First public release. What's new:

- Redesigned CD player: scrolling track list, seek bar, and pause.
- Menu OK and Menu Back are now mappable, and the mapper shows the exact
  button or key you press.
- Volume fix and a new mute toggle.
- Keyboard remapping.
- Automatic updates, with rollback if an update fails to boot.
